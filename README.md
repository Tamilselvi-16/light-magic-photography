# Light Magic Photography

Welcome to **Light Magic Photography** — where every frame tells a story!  
This project is a fully responsive photography portfolio website designed to showcase professional photography services, creative team highlights, and easy contact access.

---

## **About the Project**

**Light Magic Photography** captures emotions, not just images.  
This website was designed to reflect elegance, creativity, and professionalism — bringing out the true magic behind every shot.

It includes:
- Engaging hero section with smooth scroll.
- Detailed service and features showcase.
- Functional contact form powered by **Formspree**.
- Beautiful footer with integrated Instagram link.
- Responsive design that works across devices.

---

##  **Technologies Used**
- **HTML5** – Structure and content layout  
- **CSS3** – Styling and animations  
- **Font Awesome** – For clean, modern icons  
- **Google Fonts (Inter)** – For modern typography  
- **Formspree** – To collect form submissions easily
